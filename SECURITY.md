# Security policy

This is a local-first personal demo. It is not designed for sensitive client records or team use.

- Do not include API keys, credentials, private messages, or personal data in an issue.
- Report a security concern privately to the repository owner rather than opening a public issue.
- JSON project import is limited and validated, but browser `localStorage` is not a secure vault.
- The sample site does not accept uploads or make authenticated requests.
